# HetuSafe — Frontend

React 19 PWA frontend for HetuSafe. See the [root README](../README.md) for project overview, architecture, and setup instructions.

## Dev server

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production bundle → dist/
```

Copy `.env.example` to `.env` and fill in the Firebase, API, and observability variables before running.
